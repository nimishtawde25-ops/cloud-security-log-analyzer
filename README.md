# 🛡️ Cloud Security Log Analyzer

A professional Python and Flask-based defensive security monitoring platform that analyzes security logs, detects suspicious activity, calculates risk, generates alerts, and displays security events through a web dashboard.

## ✨ Features

### 🔐 Authentication

- Login system
- Logout functionality
- Session-based authentication
- Secure session configuration
- HTTP-only cookies
- SameSite cookie protection

### 📊 Security Dashboard

- Total security events
- Critical events
- High-severity events
- Medium-severity events
- Low-severity events
- Alert history
- Risk scores
- Risk levels
- IP addresses
- Usernames
- Event timestamps

### 🔎 Log Analysis

The analyzer can detect security-related events including:

- Failed login attempts
- Unauthorized access
- Permission denied
- Successful login
- Suspicious activity
- Repeated authentication failures

### 🚨 Threat Detection

The project includes:

- Brute-force detection
- Suspicious IP analysis
- Attack-pattern detection
- Threat classification
- Threat correlation
- Risk scoring
- Severity classification

### 📈 Risk Analysis

Security events can contain:

- Risk score
- Risk level
- Severity
- Priority
- Confidence
- Incident type
- Attack stage
